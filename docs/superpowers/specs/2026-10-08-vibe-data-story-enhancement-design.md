# AI生产力引擎 Vibe知识叙事与数据可视化升级设计

## 1. 升级目标

本轮升级不改变网站“AI如何成为新质生产力”的核心命题，也不把网站改造成自动播放视频。升级目标是把现有六幕互动页面改造成一部可由用户控制节奏的互动知识纪录片：

- 用更完整的事实、案例和限定条件提高文本质量；
- 用电影化的知识表达建立开场钩子、递进冲突和章节回收；
- 用真实数据图表补足“为什么是现在”和“扩散是否均匀”的证据；
- 让滚动、点击、拖动和悬停产生明显且可解释的视觉变化；
- 保持纯前端、GitHub Pages部署和五分钟实际网站录屏的交付边界。

视觉参考是近期“Vibe知识大赏”类知识视频的镜头语法，不复制具体视频素材或界面。网页实际引入`remotion`和`@remotion/player`。核心数据章节使用可嵌入、可播放、可拖动时间轴并能接收实时输入的Remotion Composition。网站仍保持纯前端，GitHub Pages只负责加载Player与静态资源，不在访客浏览器中渲染MP4。后续讲解视频可以复用同一Composition在本地导出。

## 2. 核心表达原则

### 2.1 观点不变

完整因果链仍为：

```text
数据 + 算力 + 算法
        ↓
识别 + 预测 + 生成 + 决策
        ↓
智能判断进入生产流程
        ↓
等待、返工、资源配置和创新搜索方式改变
        ↓
成本、周期、质量和能力边界改变
        ↓
产业、岗位与社会成本改变
        ↓
治理决定生产力是否可持续
```

### 2.2 每一幕统一使用五段结构

```text
反常识问题 → 用户操作 → 视觉变化 → 数据证据 → 一句结论
```

页面不在章节开头一次性给出全部答案。用户完成关键操作后，章节结论才出现。

### 2.3 动效只承担四种职责

- 层级：告诉用户当前应该看哪里；
- 叙事：按因果顺序揭示知识；
- 反馈：确认用户的操作已经生效；
- 状态变化：让流程、风险或结果的改变变得可见。

任何无法归入以上职责的循环动画、粒子或转场均不加入。

## 3. 新版章节结构

### 3.1 开场：一次判断

开场仍使用精准喷洒案例，但由一次点击升级为“一条线的五镜头叙事”。同一条细线同时承担叙事者、进度轨迹和视觉锚点：

1. 白色细线从左侧进入，沿植物轮廓画出识别框，页面提出“喷，还是不喷？”；
2. 线条分叉成数据流路径，进入中央几何核心；
3. 线条穿出核心后变为橙色，锁定杂草并折向喷嘴；
4. 同一条线复制、分叉并铺满画面，形成规模化路径网络；
5. 所有路径回收成一句话：“生产力变化的起点，是判断成本下降。”

这段开场使用原生SVG与GSAP path drawing，不为了统一技术而强行放进Three.js或Remotion Player。用户可以点击继续，也可以使用滚轮推进。减少动效模式直接显示五步静态流程。

文本增加案例范围和证据限制，不把John Deere厂商披露外推为全部农业场景。

### 3.2 为什么是现在：AI采用正在加速

这是本轮新增的核心数据章节。章节标题为：

> AI扩散不是一条线

副标题解释：企业正在从单点试用走向多技术组合，但企业规模、行业和地区决定扩散速度。

章节主体为一张由Remotion Player驱动的点阵重组图表，包含四个场景。Composition使用固定数量的圆点和短线段作为视觉单元。不同场景只改变同一组单元在坐标系中的目标位置、分组、标签和连接关系，不进行复杂SVG路径插值。

#### 场景A：采用深度

| 使用深度 | 2023 | 2024 | 2025 |
| --- | ---: | ---: | ---: |
| 至少一种AI技术 | 8.1% | 13.5% | 20.0% |
| 至少两种AI技术 | 4.1% | 7.8% | 13.0% |
| 至少三种AI技术 | 2.1% | 4.3% | 8.3% |

视觉单元按年份和采用深度排列成三条上升轨迹，强调企业正在由单一工具走向多能力组合。

#### 场景B：企业规模裂缝

| 企业规模 | 2024 | 2025 |
| --- | ---: | ---: |
| 全部企业 | 13.48% | 19.95% |
| 小型企业 | 11.21% | 17.00% |
| 中型企业 | 20.97% | 30.36% |
| 大型企业 | 41.17% | 55.03% |

同一组点离开年份坐标，按企业规模重新分组。大型企业的点向右上方聚集，小型企业的点停留在左下区域。右侧直接标注2025年大型与小型企业之间约38个百分点的差距。

#### 场景C：技术进入哪些任务

点阵重新排列成技术栈。重点展示文本分析、图像与媒体生成、文字与语音生成、语音识别、图像识别、机器学习分析、工作流与决策辅助、机器自主行动。

用户悬停技术类型时，图表下方同步高亮其常见生产环节。这里表达能力与流程的关系，不宣称统计数据能够证明具体生产率变化。

#### 场景D：国家扩散差异

点阵按照2025年各国采用率重新分布为排名带，不绘制没有地理坐标依据的装饰地图。全部国家保留为背景点，重点标注：

- 丹麦42.03%；
- 芬兰37.82%；
- 瑞典35.04%；
- 欧盟平均19.95%；
- 保加利亚8.55%；
- 波兰8.36%；
- 罗马尼亚5.21%。

该场景不把国家排名解释为AI生产率排名，只说明企业采用率的扩散差异。

#### 图表交互

- 首次进入章节时由Remotion Player播放一次点阵生长、分组、重组和展开；
- `PlayerRef.seekTo()`把滚动进度映射为Composition帧数；
- 用户可以播放、暂停和拖动时间轴；
- 场景内可点击图例隐藏或显示系列；
- 悬停显示十字准线、年份、值和同比变化；
- 点击数据点可锁定注释，便于课堂讲解；
- 时间游标只吸附到有观测值的年份，不显示伪造的年度中间值；
- 自由探索模式允许用户直接切换四个场景；
- 键盘左右键切换年份，Tab可访问所有系列控制；
- `prefers-reduced-motion`下不播放路径动画，直接显示完整图表。

时间轴主权必须唯一。默认状态为“主线模式”，滚动进度驱动Player帧。用户拖动Player时间轴或点击播放控制后进入“手动模式”，当前章节内的滚动不再调用`seekTo()`。用户点击“回到主线”，或者滚动离开当前章节并跨过下一章节20%的进入阈值后，恢复滚动驱动。模式切换只发生一次，不允许滚动与拖动在同一帧争夺Player控制权。

数据统一采用Eurostat `isoc_eb_ai`及其2026专题材料，避免把统计口径不同的OECD、Stanford和企业调查画在同一条线上。

### 3.3 要素重组：判断如何形成

现有三张静态卡片改为一个可破坏的机械支撑结构。数据、算力和算法表现为三个相互咬合的齿轮与三角支点：

- 数据决定系统能看见什么；
- 算力决定判断能否在流程允许的时间内完成；
- 算法决定输入如何转化为识别、预测、生成和决策。

用户可依次关闭或降低任一要素。数据不足时齿轮空转，路径出现断点；算力不足时脉冲减速并在入口堆积；算法不匹配时脉冲沿错误出口分流。故障本身是知识动作，不弹出脱离画面的错误卡片。这里不增加虚构精确分数，只表现因果方向。

齿轮、支点和路径全部使用2D SVG绘制，咬合、空转和断点由GSAP路径与旋转动画表现，不建立3D齿轮模型。Three.js只保留给决策脉冲的空间纵深、行业网络和风险裂缝。

现实锚点使用工信部的人工智能产业规模、企业数量、数字化研发工具普及率和关键工序数控化率，以及Stanford AI Index的推理成本下降数据。不同来源分别展示，不合并为统一指数。

### 3.4 流程重构：工具不等于生产力

现有“传统流程、AI辅助、人机协同”按钮改为双轨电路板：

- 上轨是一条从发现到检查的实线路径，等待节点表现为圆形卡点；
- 下轨是可以重新布线的AI介入路径；
- 用户拖动介入点，选择AI进入发现、方案、执行或检查环节；
- 等待、返工、信息回流和人工复核节点实时重排；
- “只加工具”只在原有卡点旁增加局部旁路；
- “重构流程”形成折返上游的信息闭环。

章节加入NBER客服研究和世界经济论坛灯塔工厂案例。每项数据同时显示样本范围、指标和证据类型，不能直接比较不同案例的百分比大小。

### 3.5 生产力证据墙

现有三案例结构保留“节约型、增效型、创造型”递进，但增加一张证据点图：

- 横轴表示报告中的结果变化幅度；
- 纵向按研发、生产、服务、科研分组；
- 圆形代表独立研究或官方资料；
- 菱形代表企业披露；
- 实心代表`verified`，空心代表`qualified`；
- 用户可筛选效率、质量、成本和能力边界；
- 悬停显示方法、样本、年份、限制和来源。

由于不同指标不可直接比较，横轴只在同类指标组内使用共同尺度。跨组案例通过分面排列，不使用统一排名。

首批案例包括精准农业、软件开发、客服、智能制造、AlphaFold和AI医疗器械。案例必须满足数据台账的准入规则。

### 3.6 行业星图：能力如何迁移

行业节点扩展为智能制造、精准农业、软件与服务、医疗健康和科学研究。星图不使用不可比数据控制节点大小。

- 外环分段表示识别、预测、生成、决策和人工复核；
- 内部纹理区分成本、周期、质量和能力边界；
- 连线只表示共享能力，不表示投资额或因果强度；
- 点击节点展开“问题、介入、流程变化、结果、限制”五段式案例；
- 移动端继续使用行业列表与能力关系图，不实现拖拽星图。

### 3.7 生产力实验室2.0

保留AI投入、数据准备、流程适配和人员训练四个参数，以及确定性的互补性公式。

新增三个情景预设：

- 高投入、低培训；
- 数据丰富、流程落后；
- 均衡的人机协同。

预设只负责设置输入，不硬编码结果。结果区新增“有效收益”和“转型摩擦”两个组成部分，并高亮当前瓶颈滑块。三维决策环根据协同基础出现断裂、抖动或闭合。

状态文案继续强制包含瓶颈、因果位置和下一步建议。

### 3.8 增长的阴影

风险章节由四张观点卡片升级为三组数据与治理交互：

1. 能源：IEA数据中心用电量从2024年约415 TWh到2030年约945 TWh，预测区间使用虚线和斜纹；
2. 就业：WEF对2030年岗位新增、岗位替代和技能变化的调查预测，使用任务流动图，不把预测当作确定事实；
3. 治理：参考NIST AI RMF，将可靠、安全、透明、隐私、公平和责任设计为机械限位环。

系统核心表现为高速旋转的圆环，治理措施表现为外部约束爪。用户松开约束时，圆环加速、抖动并出现裂纹；收紧约束时，转速下降、裂纹愈合，同时更多人工复核节点亮起。系统速度、错误传播范围、人工复核节点和风险裂缝同步改变，明确表达治理能够降低风险但也需要资源投入。

### 3.9 结论：替代还是增强

保留最终控制轴，但强化与前文的回收：

- 偏向替代时，网络节点减少、路径变短、速度提高；
- 偏向增强时，人的复核、培训和新任务节点增多；
- 页面同时显示效率与能力边界的变化，不把增强描述成没有成本的选择。

最终结论保持：AI不是天然的生产力。技术只有进入合适流程、被人正确使用并受到有效治理，才能转化为可持续的新质生产力。

## 4. 引导系统

每个章节增加三类引导，但不使用“向下滚动”之类冗余提示：

- 因果链定位：显示当前位于要素、能力、流程、结果或治理；
- 操作提示：一句具体动词，例如“拖动介入点，观察返工路径”；
- 完成反馈：操作后出现一句本幕结论和进入下一幕的按钮。

顶部导航保持单行。新增“主线模式”和“自由探索模式”：

- 主线模式按既定镜头推进，适合初次访问和五分钟视频；
- 自由探索模式开放图表系列、案例筛选和来源详情；
- 两种模式共享同一份内容和组件，不维护两套页面。

## 5. 视觉与动效系统

### 5.1 视觉定位

```text
DESIGN_VARIANCE: 9
MOTION_INTENSITY: 9
VISUAL_DENSITY: 7
```

延续工业编辑式暗色主题、熔融橙强调色、无彩虹行业配色。数字使用等宽字体。图表不包进通用仪表盘卡片，而是作为章节的主要视觉场景。

### 5.2 Remotion式镜头语法

- 每个镜头只强调一个观点；
- 文本、数据和图形同步出现；
- 前一场景的视觉对象变形成下一场景；
- 转场优先使用位置、尺度、路径和透明度变化；
- 章节末保留短暂停顿，让结论可阅读；
- 不使用全屏霓虹、扫描线、持续呼吸缩放或无意义故障效果。

### 5.3 统一知识动作

整站不为每一幕发明一种完全不同的特效，而是使用五种可复述的视觉动作：

- 线的生长表示判断链条延伸；
- 点阵重组表示采用扩散不均匀；
- 齿轮空转表示生产要素缺失；
- 电路重布线表示流程重构；
- 机械限位表示治理对速度和风险的约束。

这些动作跨章节复用相同的线宽、橙色激活态、缓动和节奏。用户应能在不阅读长文的情况下理解状态发生了什么变化。

| 视觉属性 | 统一规范 |
| --- | --- |
| 主线线宽 | 2px |
| 辅助线线宽 | 1px |
| 激活线线宽 | 3px |
| 激活色 | `#F26A2E`，决策、锁定和激活状态共用 |
| 中性色 | `rgba(236, 235, 228, 0.42)`，未激活路径共用 |
| 普通出场缓动 | `power2.out` |
| 点阵与结构重组 | `power3.inOut` |
| 故障反馈 | `elastic.out(1, 0.45)`，只执行一次，不循环 |
| 单动作时长 | 0.6-0.9秒 |
| 章节结论停顿 | 1.2秒 |

移动端保持相同线宽语义，不按视口等比缩细。低性能和减少动效模式保留颜色、线宽和静态状态差异。

### 5.4 技术分工

- React管理离散状态和用户选择；
- `remotion`与`@remotion/player`负责采用率主图的固定帧Composition、播放控制和数据驱动镜头；
- 原生SVG负责点阵、坐标轴、标注和命中区域，并在Remotion Composition中复用；
- GSAP ScrollTrigger负责章节钉扎、开场路径绘制，以及把滚动进度转换为Remotion目标帧；
- Three.js负责决策脉冲、空间网络和风险裂缝；
- CSS负责数字滚动、文本遮罩和普通状态反馈；
- 不新增D3或通用图表库，现有图表尺度计算由小型纯函数完成。

同一元素只由一种动画系统控制。采用率主图内部以Remotion帧为唯一动画时间源，GSAP只调用`PlayerRef.seekTo()`，不直接修改Composition内的SVG元素。连续指针值和滚动进度不写入React状态。

Composition默认30fps，时长控制在18-22秒。Player进入视口时才懒加载，离开视口后暂停。网页不调用客户端MP4渲染接口。

## 6. 数据架构

### 6.1 数据文件

扩展`src/data/data-ledger.json`，并增加结构化图表数据文件：

```text
src/data/data-ledger.json
src/data/adoption-series.json
src/data/evidence-cases.json
```

图表数据只保存值、维度和台账ID，不重复保存来源说明。组件通过台账ID读取来源、年份、地理范围、方法和证据等级。

### 6.2 来源等级

- `verified`：官方统计或已核对的独立研究；
- `qualified`：企业披露、平台研究或口径有限的数据；
- `pending`：不得进入正式构建。

页面中的每个数字都能定位到数据台账。预测值、历史观测和教学模拟使用不同线型和文字标识。

### 6.3 首批新增来源

- [Eurostat企业AI采用数据集](https://ec.europa.eu/eurostat/databrowser/view/isoc_eb_ai/default/table)与[2026专题](https://ec.europa.eu/eurostat/documents/7870049/23260410/KS-01-26-009-EN-N.pdf/37d063cb-28cf-3b4e-91f3-c3784c970842)；

## 8. 错误与降级

- 图表数据缺失：隐藏对应系列，并在来源区域显示数据不可用；
- Remotion Player或图表动画初始化失败：显示完整静态SVG，不阻止阅读；
- Three.js失败：保留全部SVG图表、文本和交互；
- 低性能模式：30fps模式的中位帧率低于24fps时切换为15fps，并按相同时长重新计算总帧数；15fps模式的中位帧率低于14fps时直接使用四个静态关键帧。Player仍可拖动和切换场景，但静态模式不再连续逐帧播放；
- 小于768px：图表改为纵向叙事，国家分布点图独占一屏；
- 小于420px：最多显示四个横轴刻度，重要值直接标注；
- 触摸设备：点击锁定数据提示，不依赖悬停；
- 减少动效模式：不自动播放，不钉扎章节，不使用路径绘制动画。

## 9. 验证标准

### 9.1 内容

- 每一幕都有问题、操作、证据和结论；
- 所有精确数字均有年份、范围、单位和来源；
- 不把企业披露写成独立研究；
- 不把采用率等同于生产率；
- 不把调查预测写成确定未来。

### 9.2 图表

- 折线、规模、技术类型和国家差异四个场景均使用真实数据；
- 系列切换、年份选择、数据点锁定和键盘操作可用；
- 用户拖动时间轴后进入手动模式，章节内滚动不再改写当前帧；
- “回到主线”和跨章节阈值都能恢复滚动驱动；
- 十字准线只显示观测年份，不插值伪造数据；
- 移动端标签不重叠，数值不被裁切；
- 图表具备SVG标题、描述和文本摘要；
- 所有动画支持`prefers-reduced-motion`。

### 9.3 工程

- `npm run check:data`能够验证图表中的台账ID；
- 新增数据转换逻辑有最小单元测试；
- Remotion Composition在起始帧、四个场景关键帧和结束帧具有确定输出；
- 滚动进度到目标帧的映射有边界测试；
- 手动模式与主线模式切换有状态测试，确保同一时刻只有一个帧控制源；
- `npm run test`、`npm run lint`和`npm run build`通过；
- 桌面与390px移动视口完成主线；
- 浏览器无运行时错误；
- GitHub Pages资源路径和直接访问正常。

### 9.4 视觉预检

- 全站保持一种暗色主题和一种橙色强调色；
- 页面可见文案不使用长破折号作为装饰；
- 没有重复的三等分卡片章节；
- 动效能够说明层级、叙事、反馈或状态变化；
- 主图是章节视觉中心，不被通用卡片边框包围；
- 主线模式五分钟内可以讲完，探索功能不阻塞主线。
