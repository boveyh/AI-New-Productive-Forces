# 连续叙事与可解释控制设计

## 目标

现有网站已经具备独立的动态图表、要素机械、流程电路、案例、模拟器和治理环，但章节之间仍像多个演示模块。此次改造要让评审在进入页面后的前二十秒内理解主问题，并在全程持续看到同一条因果链：

`判断成本下降 → AI能力进入任务 → 生产要素重新组合 → 流程被重构 → 生产结果改变 → 新风险要求新治理`

网站继续以精准农业中的“喷，还是不喷”为贯穿案例。它不是唯一案例，而是一条用于理解所有章节的叙事线索。

## 一、修复 Remotion 国家场景

- Composition 顶部固定保留标题区，数据绘图区不得进入标题区。
- 国家排行首行从标题区下方开始，七个国家在剩余高度内等距排列。
- “同一项技术，落在不同的生产土壤里”保留为章节判断，不覆盖“丹麦”等数据标签。
- 桌面端、窄屏横向视图和 15fps 降级模式使用同一安全边距。

验收：任意帧率与四种时间轴控制状态下，标题、国家名、数值标签均不重叠。

## 二、建立贯穿全站的叙事主线

### 开场铺垫

在“喷，还是不喷”前增加三层信息：

1. 过去，扩大生产通常意味着增加更多土地、设备和劳动；
2. AI带来的变化，是把部分判断变得更快、更便宜、更可复制；
3. 网站将追踪一个田间判断，观察它如何变成生产力。

开场仍保持短促，不增加说明书式长文。

### 章节桥接

每个主要章节之间增加轻量 Story Bridge，固定回答三个问题：

- 刚刚证明了什么；
- 因果链现在走到哪里；
- 下一章必须回答什么。

桥接不是卡片，不占据完整章节，而是由一条延续的橙色线路、一个短结论和一个具体问题组成。

桥接顺序：

1. 判断产生后：一次正确判断还不是生产力，它必须可以复制；
2. 采用率之后：企业买到AI不等于获得生产力，还需要数据、算力和算法咬合；
3. 要素之后：能力具备后，决定结果的是它进入流程的位置；
4. 流程之后：流程变化必须在成本、质量、速度或新任务上留下证据；
5. 案例之后：局部成功能否扩大，取决于投入与组织条件的互补；
6. 模拟器之后：规模越大，错误、能源和责任也传播得越快；
7. 治理之后：治理不是生产力的反面，而是生产力能够持续的条件。

### 持续定位

导航下方保留一条简化因果轨迹。它只显示六个因果节点及当前节点，不重复章节名称，不成为第二套导航。

## 三、统一滑杆为可解释实验仪器

所有关键滑杆统一包含：

- 可点击的关键节点；
- 当前状态名称；
- 当前参数在因果链中的含义；
- 至少三项同步变化；
- 跨越阈值时的一次性提示；
- 键盘可操作和 `aria-live` 状态播报。

### AI介入位置

四个阶段：

1. `0–24` 流程外建议：AI只提供参考，等待基本不变；
2. `25–49` 局部任务自动化：单点加速，但交接处仍可能返工；
3. `50–74` 流程内协作：生成、复核和执行开始连续；
4. `75–100` 反馈闭环：结果回流上游，系统可以持续校正。

同步指标：任务周期、等待节点、人工复核位置、反馈完整度。

### 生产力实验室

四个输入分别提供低、中、高三个解释区间，并显示当前参数标签。例如数据准备度分为“口径分散、可用但不统一、可追溯资产”。状态结果继续使用现有四状态模型，但增加：距离下一状态的关键参数、阈值提示和四项结果拆解。

结果拆解：产出、周期、摩擦、创新能力。它们是教学模拟值，页面必须继续声明不是企业预测。

### 治理约束

四个阶段：

1. 无约束扩张；
2. 事后审计；
3. 关键节点复核；
4. 可追溯治理。

同步指标：决策速度、错误传播、人工复核、可追溯性、能耗约束。关键节点为 25、50、75。

### 自动替代到能力增强

四个阶段：任务替代、局部自动化、人机协作、能力扩展。

同步指标：任务速度、人的判断份额、新任务节点、组织连接数。结论不暗示“越靠右越好”，而是强调不同任务需要不同责任结构。

## 四、最终引申

结尾从精准农业向外展开，但不再新建行业卡片。决策脉冲分裂为四条路径：

- 研发：从搜索已有答案到生成并验证新候选；
- 制造：从事后检测到实时反馈和工艺调整；
- 医疗：从信息整理到辅助判断，但高影响责任仍由人承担；
- 组织：从层层传递信息到让判断在更接近现场的位置发生。

最终观点：

> AI成为新质生产力，不只是因为它把旧任务做快了，而是因为判断成本下降后，过去无法规模化的新任务、新产品和新组织方式开始成为可能。判断越能被复制，责任边界就越需要被重新设计。

## 五、实现边界与验收

- 不增加新的动画库；复用 React、GSAP、SVG、Three.js 与 Remotion。
- Story Bridge 使用普通 React 与 SVG，不创建新的全屏 Three.js 场景。
- 参数区间与指标映射集中为纯函数，并增加边界值测试。
- 所有阈值在 0、24/25、49/50、74/75、100 处可稳定复现。
- 减少动态效果模式下取消阈值闪烁与路径运动，但保留全部文本状态。
- 桌面端与 375px 宽度下，Remotion 国家标签、滑杆节点和状态文本不得互相遮挡。
- `npm run check:data`、`npm test`、`npm run lint`、`npm run build` 全部通过后才能部署。
